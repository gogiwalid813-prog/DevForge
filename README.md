# DevForge

منصة مطورين موحدة لإدارة المشاريع والكود والتعاون والذكاء الاصطناعي.

## التقنية
- React + TypeScript + Vite
- Firebase Authentication
- Cloud Firestore
- تصميم RTL متجاوب للهاتف

## تشغيل المشروع
```bash
npm install
npm run dev
```

ثم أنشئ ملف `.env` اعتمادًا على `.env.example` وضع إعدادات Firebase الخاصة بمشروعك.

## بنية المنتج
- Dashboard
- Projects
- Project Workspace
  - Code
  - Tasks
  - Issues
  - Pull Requests
  - Roadmap
  - Team
  - Documentation
  - Releases
  - Deploy
- AI Assistant
- Teams
- Deploy & Security
- Profile

> هذا المستودع هو مشروع واحد. الوحدات تُبنى داخله تدريجيًا مع الحفاظ على نفس البنية، وليست نسخًا منفصلة.
